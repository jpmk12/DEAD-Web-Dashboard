Callouts — what changes and why

  1. 1Select text anywhere → “⧉ Append to…” — a floating chip on any selection in the app (News, OSINT, Email, a chat answer, the SITREP). One tap, no tab flip.
  2. 2A thesis (and every Save-to-Docs button) gets two verbs: append to a log, or save as a new doc. The first shows the log you used last for this subject.
  3. 3The Append picker: your logs first (most recently appended first, aliases and tags searched), other docs after, and “New log” last. Same shape as the Track picker.
  4. 4The entry is a dated heading with the text, the source line and a wiki-link to the thread — editable before it lands; the article is recorded as a link so the log shows in the article’s backlinks.
  5. 5Docs opens on the logs (a new 📓 doc type), newest entry on top, rather than “No document selected”.
  6. 6The whole Files pane is the drop zone, folders included; a queue shows each file’s state and lets one failure be retried without re-dropping the rest.
  7. 7Multi-select + bulk bar for files: tag, attach to a doc, download as one .zip, delete — the Docs list already has this; Files had none.
  8. 8Download is a button, on every row and in the viewer header, with “Open in new tab” for PDFs.
  9. 9PDF preview was blocked by our own CSP (`frame-src` without `'self'`, and `frame-ancestors 'none'` applied to the file response itself). A header fix, not a viewer rewrite.
